# Portfolio Website dengan CMS Bawaan 🌐

## Problem
Kebanyakan portfolio developer tampilannya bagus tapi susah di-update. Mau tambah project baru harus edit kode. Mau tulis blog harus sentuh database. Akhirnya portfolio tidak pernah di-update dan terlihat usang.

## Solution
Website portfolio profesional yang bisa dikelola seperti CMS — tanpa database, tanpa kompleksitas:
- Tampilan modern dengan **scroll snap** antar section yang mulus
- Konten blog dan testimoni dikelola via **Markdown** — tulis, simpan, tampil. Sesederhana itu
- **Admin panel** untuk tambah/hapus blog post dan testimoni langsung dari browser
- Desain responsif untuk semua ukuran layar
- SEO-ready dan cepat (Next.js)

## Result
- Portfolio bisa di-update kapan saja tanpa sentuh kode
- Konten tersimpan di Git — tidak ada risiko kehilangan data
- Kesan profesional yang konsisten ke calon klien
